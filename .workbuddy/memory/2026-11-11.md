## 11:0x 面板「连不上」排障与修复（重要教训）
- 现象：用户报「还没有连接上」。逐段验证：页面 `/` 返 200、本地 `/api/q` 正常，但**线上 `/api/q` 返回 `{"ts":...,"q":{}}`** → 服务器侧抓新浪拿到空内容，前端因此一直报「行情字段缺失」。
- **根因两条**：① 线上数据中心出网抓 `hq.sinajs.cn` 不稳定（同一份代码本地 11/11 成功、线上 0/11）；② **访问路径不带 `?sharecode=` 时网关直接返 403**（`/` 无参数 = 403，2988 字节错误页），复制链接丢参数就表现为「打不开/连不上」。
- **修复**：`server.js` 改成**双源自动 fallback**（新浪 → 东方财富 push2），加 AbortController 5s 超时与 `/api/diag` 诊断端点；前端再叠一层**浏览器直连东财 JSONP**（不受服务器出口限制，`&cb=` 回调，已验证带跨域 Referer 正常返回），失败才回落 `/api/q`；轮询 3s→5s 并加 `inFlight` 锁防请求堆积。
- **东财 secid 口径（关键）**：郑商所 3 位 `115.TA701 / PX701 / FG701 / FG705 / SH701 / SH705 / UR701 / RM701`；大商所 4 位 `114.jm2701 / m2701 / pp2701`。字段：f2 最新、f15 高、f16 低、f17 开、f18 昨收、**f28 昨结算**、f31 买一、f32 卖一、f5 成交量。
- 修复后线上 `/api/q`：src=eastmoney、11/11 合约、TA 5990 / PX 8380 / FG 880·924 / SH 1549·1727 / JM 1414.5 / PP 9120。
- **教训沉淀：托管应用的「连不上」必须分三层排查——① 页面 HTTP 状态（含 sharecode 鉴权）② 服务端接口原始返回 ③ 服务端出口可达性。只有第②③层都验过，才能断定是浏览器侧问题。**
